### 👨‍💻 Rólam

Érdeklődő és technológia-orientált egyetemi hallgató vagyok az **Eötvös Loránd Tudományegyetem Savaria Egyetemi Központjában (ELTE IK BSc)**, szoftverfejlesztő és tesztelő technikusi képesítéssel. Informatikai szemléletmódom segít a komplex problémák logikus és tiszta megoldásában.

- 🎓 **Tanulmányok:** Eötvös Loránd Tudományegyetem (ELTE IK) – Programtervező informatikus (BSc)
- 💻 **Fő szakterületek:** Modern webfejlesztés (React, PHP 8 REST API, MySQL), adatbázis-kezelés és szoftvertesztelés
- 🚀 **Élő weboldalam és portfólióm:** [https://jannn1.hu](https://jannn1.hu)
